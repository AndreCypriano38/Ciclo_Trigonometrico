# Ciclo_Trigonometrico
Site desenvolvido com IA para auxiliar nos estudos de trigonometria
Contém:
-Slider para selecionar a abertura do arco
-Demonstração visual e algébrica das razões trigonométricas
-Tabela de presets com ângulos notáveis
-Legenda seletiva para analisar as razões trigonométricas de forma separada
